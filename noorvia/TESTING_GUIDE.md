# 🧪 আযান অ্যালার্ম টেস্টিং গাইড

## ⚠️ গুরুত্বপূর্ণ নোট

**আযান অ্যালার্ম সিস্টেম শুধুমাত্র Android/iOS ডিভাইসে কাজ করবে।**

ওয়েব ব্রাউজারে (Chrome/Edge) এই ফিচারগুলো কাজ করবে না:
- ❌ Push Notifications
- ❌ Background Alarms
- ❌ Exact Alarm Scheduling
- ❌ Full Audio Playback

---

## 📱 Android/iOS ডিভাইসে টেস্ট করুন

### ধাপ ১: ডিভাইস কানেক্ট করুন

#### Android ডিভাইস:
```bash
# USB Debugging চালু করুন
# Settings → Developer Options → USB Debugging

# ডিভাইস চেক করুন
flutter devices
```

#### iOS ডিভাইস (Mac এ):
```bash
# Xcode দিয়ে ডিভাইস কানেক্ট করুন
flutter devices
```

### ধাপ ২: অ্যাপ রান করুন

```bash
# Android এ রান করুন
flutter run

# তারপর ডিভাইস সিলেক্ট করুন (Android/iOS)
```

## 🐛 কমন সমস্যা ও সমাধান

### সমস্যা ১: নোটিফিকেশন আসছে না

**সম্ভাব্য কারণ:**
- নোটিফিকেশন পারমিশন দেওয়া হয়নি
- Battery optimization চালু আছে
- Exact alarm পারমিশন দেওয়া হয়নি

**সমাধান:**
```
1. Settings → Apps → Nurvia → Notifications → Allow
2. Settings → Apps → Nurvia → Battery → Unrestricted
3. Settings → Apps → Nurvia → Alarms & reminders → Allow
```

### সমস্যা ২: আযান বাজছে না

**সম্ভাব্য কারণ:**
- ইন্টারনেট কানেকশন নেই
- ভলিউম ০% আছে
- অডিও পারমিশন নেই

**সমাধান:**
```
1. ইন্টারনেট কানেকশন চেক করুন
2. ভলিউম বাড়ান
3. অন্য আযান সিলেক্ট করে দেখুন
```

### সমস্যা ৩: অ্যাপ বন্ধ থাকলে কাজ করছে না

**সম্ভাব্য কারণ:**
- Battery optimization চালু আছে
- Background app refresh বন্ধ আছে

**সমাধান:**
```
1. Settings → Apps → Nurvia → Battery → Unrestricted
2. Settings → Apps → Nurvia → Background data → Allow
```

### সমস্যা ৪: অ্যালার্ম সময়মত বাজছে না

**সম্ভাব্য কারণ:**
- ডিভাইসের সময় ভুল
- টাইমজোন ভুল
- নামাজের সময় আপডেট হয়নি

**সমাধান:**
```
1. Settings → Date & Time → Automatic date & time (চালু করুন)
2. অ্যাপে লোকেশন পারমিশন দিন
3. নামাজের সময় রিফ্রেশ করুন
```
