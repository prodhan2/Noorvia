## 💡 প্রো টিপস

### টিপ ১: Hot Reload ব্যবহার করুন
অ্যাপ রান করার পর, কোড পরিবর্তন করলে:
- **r** চাপুন = Hot Reload (দ্রুত)
- **R** চাপুন = Hot Restart (পুরো রিস্টার্ট)

### টিপ ২: Debug Console দেখুন
Console এ লগ দেখবেন:
```
🎵 Playing azan: https://...
✅ Started playing online azan
```

### টিপ ৩: APK বিল্ড করুন
যদি অন্য ফোনে ইনস্টল করতে চান:
```bash
flutter build apk --release
```
APK পাবেন: `build/app/outputs/flutter-apk/app-release.apk`
