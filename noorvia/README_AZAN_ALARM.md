## 🔧 প্রযুক্তিগত বিবরণ

### ব্যবহৃত প্যাকেজ
- `flutter_local_notifications` - পুশ নোটিফিকেশনের জন্য
- `audioplayers` - অডিও প্লেব্যাকের জন্য
- `shared_preferences` - ডেটা সেভ করার জন্য
- `timezone` - টাইমজোন হ্যান্ডলিংয়ের জন্য
- `provider` - স্টেট ম্যানেজমেন্টের জন্য

### আর্কিটেকচার
```
UI Layer (Pages)
    ↓
State Management (Provider)
    ↓
Business Logic (Service)
    ↓
External Services (islamcan.com)
```

### ডেটা ফ্লো
```
User Action → Provider → Service → Notification/Audio
```

## ⚠️ গুরুত্বপূর্ণ নোট

### 1. শুধু মোবাইলে কাজ করবে
আযান অ্যালার্ম সিস্টেম **শুধুমাত্র Android/iOS** ডিভাইসে কাজ করবে।
ওয়েব ব্রাউজারে (Chrome/Edge) কাজ করবে না।

### 2. পারমিশন প্রয়োজন
অ্যাপ চালু করলে এই পারমিশনগুলো চাইবে:
- ✅ Notification Permission
- ✅ Exact Alarm Permission
- ✅ Internet Permission

### 3. ব্যাটারি অপটিমাইজেশন
অ্যাপ বন্ধ থাকলেও অ্যালার্ম কাজ করার জন্য:
```
Settings → Apps → Nurvia → Battery → Unrestricted
```

### 4. ইন্টারনেট প্রয়োজন
আযান বাজানোর জন্য ইন্টারনেট কানেকশন প্রয়োজন (অনলাইন আযান)।

## 🐛 সমস্যা সমাধান

### নোটিফিকেশন আসছে না?
```
Settings → Apps → Nurvia → Notifications → Allow
Settings → Apps → Nurvia → Battery → Unrestricted
Settings → Apps → Nurvia → Alarms & reminders → Allow
```

### আযান বাজছে না?
```
1. ইন্টারনেট কানেকশন চেক করুন
2. ভলিউম বাড়ান

```

### অ্যাপ বন্ধ থাকলে কাজ করছে না?
```
Settings → Apps → Nurvia → Battery → Unrestricted
Settings → Apps → Nurvia → Background data → Allow
```
